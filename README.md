# Mandi Darbar

A royal Hyderabadi restaurant ordering site - menu, cart, table reservations,
delivery zones, and an admin/staff dashboard, built as a front-end demo.

**Live demo:** https://mandi-darbar.vercel.app/

## What it is

Next.js 14 + Tailwind + Framer Motion + Zustand. No backend: data is mocked in
localStorage (stores in `/store`), brand config in `restaurant.config.ts`.

## Run

```
npm i
npm run dev
```

Tests: `npm test`

Demo logins - admin: `admin@mandidarbar.demo` / `admin123`,
staff: `staff@mandidarbar.demo` / `staff123`.
